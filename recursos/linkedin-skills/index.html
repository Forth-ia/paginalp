11 LinkedIn Skills: guía completa para Claude, Codex y otros agentes de AI

Instala 11 Skills para escribir, humanizar, auditar, planificar y publicar contenido de LinkedIn con agentes de AI.

9 min de lecturaContenido y LinkedInClaudeCodex
Ideal para
  • Founders que quieren generar conversaciones desde LinkedIn
  • Equipos que crean contenido con Claude o Codex
  • Personas que quieren conservar su voz usando AI
  • Quien quiere reutilizar contenido en posts nativos
Qué obtienes
  • Los 11 Skills y cuándo usar cada uno
  • Instalación según tu agente
  • Prompts listos para copiar
  • Un flujo semanal de contenido
  • Conexiones opcionales y seguridad
LinkedIn Skills es un paquete gratuito de 11 Skills especializados para escribir, humanizar, revisar, planificar y reutilizar contenido de LinkedIn con Claude, Codex y otros agentes de IA.

Repositorio: sergebulaev/linkedin-skills. No es un prompt aislado: Claude selecciona automáticamente el Skill indicado según la tarea que le pidas.

1) Los 11 Skills incluidos

SkillQué hace
Post WriterEscribe posts con 20 fórmulas de hooks y ángulos para founders.
Comment DrafterCrea comentarios de valor a partir de la URL de un post.
Reply HandlerRedacta respuestas para conversaciones y comentarios.
Post AuditRevisa estructura, distribución y señales de texto de AI.
HumanizerElimina patrones repetitivos y vocabulario genérico.
Hook ExtractorConvierte hooks que funcionan en plantillas reutilizables.
Content PlannerCrea un plan de contenido de 7 días.
Engagement MonitorAnaliza y agrupa a quienes interactúan.
Profile OptimizerReescribe Headline, About, Featured y Experience.
Employee AdvocacyDiseña un programa de LinkedIn para equipos.
RepurposerConvierte tweets, videos, blogs y newsletters en posts.

2) Instalación rápida

Claude web: abre Skills en la barra lateral, pulsa Add from GitHub, introduce sergebulaev/linkedin-skills, termina la instalación y abre una conversación nueva.

Claude Desktop: sigue Customize → + junto a Personal plugins → Create plugin → Add marketplace → Add from a repository. Pega el mismo repositorio, instala y abre una conversación nueva.

Claude Code

plain text
/plugin marketplace add sergebulaev/linkedin-skills
/plugin install linkedin-skills@linkedin-skills

Codex

bash
codex plugin marketplace add sergebulaev/linkedin-skills
codex plugin add linkedin-skills@linkedin-skills

Un comando para agentes compatibles

bash
npx skills add sergebulaev/linkedin-skills

En OpenClaw, clona el repositorio en tu directorio de trabajo e indícale en el system prompt que lea el SKILL.md relevante antes de cada tarea de LinkedIn.

3) Prompts para empezar

Escribir un post

plain text
Escribe un post de LinkedIn sobre por qué las agencias de AI están reemplazando a las agencias tradicionales.

Soy founder. Elige un hook fuerte para conseguir alcance, mantenlo específico y muéstrame el borrador antes de publicar cualquier cosa.

Humanizar un post

plain text
Humaniza este post de LinkedIn. Elimina vocabulario típico de AI, guiones largos, estructuras repetitivas y afirmaciones genéricas.

Mantén mi punto original y mi forma de escribir:

[pega aquí el post]

Auditar antes de publicar

plain text
Audita este post de LinkedIn teniendo en cuenta fuerza del hook, claridad, señales de texto generado por AI, formato y posibles puntos de abandono.

Explícame las tres mejoras de mayor impacto y después dame una versión revisada:

[pega aquí el post]

Crear un plan semanal

plain text
Crea un plan de contenido de LinkedIn de 7 días para un founder que vende automatizaciones con AI a pequeñas y medianas empresas.

Incluye tema, formato, hook, hora de publicación, CTA y cinco cuentas o tipos de audiencia con los que debería interactuar cada día.

4) El flujo de trabajo semanal

Lunes: usa Content Planner para generar ideas para siete días. Escoge entre tres y cinco que conecten con tu oferta, resultados, experiencia y trabajo actual.

Antes de cada publicación: dale a Post Writer una audiencia, idea central, prueba o ejemplo, oferta, CTA y tono. Cuanto más específico sea el input, mejor será el borrador.

Antes de publicar: pásalo por Post Audit, después por Humanizer y léelo en voz alta. El objetivo no es que sea perfecto: es que siga sonando a ti.

Después de publicar: usa Comment Drafter en posts relevantes y Reply Handler para responder en los tuyos.

Al final de la semana: mide visitas al perfil, comentarios relevantes, mensajes directos y conversaciones calificadas; no solo impresiones.

5) Conexiones opcionales

El paquete funciona sin Apify. Si no puede leer una publicación, te pedirá pegar el contenido. Para leer posts, comentarios y actividad automáticamente, guarda un token privado en .env:

plain text
APIFY_TOKEN=apify_api_tu_token_aqui

Publora añade programación y publicación directa; los Skills crean borradores por defecto y esperan aprobación. Sus credenciales también van solo en .env:

plain text
PUBLORA_API_KEY=sk_tu_key_aqui
LINKEDIN_PLATFORM_ID=linkedin_tu_id_aqui

Importante: no compartas ni subas tokens a GitHub. Añade .env a tu .gitignore y revisa cada post, comentario, respuesta o publicación programada antes de aprobarla.

6) Cómo conseguir mejores resultados

  1. Dale a Claude una opinión, experiencia o argumento real; no pidas simplemente “un post viral”.
  2. Añade pruebas: números, resultados, historias de clientes, errores o detrás de cámaras.
  3. Define una sola audiencia y una sola acción deseada.
  4. Usa Humanizer como editor, no como autoridad final: protege tu voz.
  5. Mantén siempre la aprobación antes de publicar.

La versión corta: instala el repositorio, abre una conversación nueva, pide un post, auditoría o mejora de perfil, revisa el resultado y publica únicamente cuando de verdad suene como tú. El flujo es: Crear → Revisar → Aprobar → Publicar.
