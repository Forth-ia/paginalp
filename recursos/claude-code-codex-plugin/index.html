Cómo trabaja Claude Code + Codex: Plugin Oficial

Instala el plugin oficial y divide el trabajo: Claude piensa, planea y revisa; Codex ejecuta el trabajo pesado.

12 min de lecturaClaude a fondoClaude CodeCodex
Ideal para
  • Quien usa Claude Code y Codex en el mismo proyecto
  • Equipos que quieren delegar sin perder supervisión
  • Developers que consumen mucho contexto arreglando errores
Qué obtienes
  • Instalación del plugin oficial, paso a paso
  • Reglas listas para tu CLAUDE.md
  • Prompts para planear, rescatar errores y revisar
  • Flujo para dividir consumo y mantener control

Cuando tus tokens se acaban a media semana, casi siempre es por lo mismo: arreglar errores gasta más que construir.

1. ¿Qué vas a construir?

La idea es crear este flujo:

Tú → Claude → Codex → Claude → Tú

Claude

  • Entender el problema.
  • Analizar el proyecto.
  • Crear el plan.
  • Decidir la arquitectura.
  • Dividir el trabajo.
  • Revisar lo que hizo Codex.

Codex

  • Escribir código y modificar archivos.
  • Hacer refactors grandes.
  • Investigar errores.
  • Ejecutar tareas repetitivas y largas.

El objetivo no es reemplazar Claude: es evitar que gaste su límite haciendo trabajo que puede delegar.

2. Instala el plugin oficial

El plugin se llama codex@openai-codex y pertenece al repositorio oficial openai/codex-plugin-cc. La instalación se hace directamente desde Claude Code.

Paso 1. Agrega el marketplace

texto
/plugin marketplace add openai/codex-plugin-cc

Paso 2. Instala el plugin

texto
/plugin install codex@openai-codex

Paso 3. Recarga los plugins

texto
/reload-plugins

Esto hace que Claude Code cargue el nuevo plugin en la sesión.

Paso 4. Configura Codex

texto
/codex:setup

Este comando comprueba que Codex esté instalado y revisa el estado de la autenticación.

3. Si Codex no está instalado

Si /codex:setup no encuentra Codex, sal de Claude Code y abre una terminal normal.

bash
npm install -g @openai/codex

Después inicia sesión:

bash
codex login

Cuando termines, vuelve a Claude Code y ejecuta /codex:setup. La autenticación la tienes que hacer tú porque abre el flujo de inicio de sesión en el navegador.

4. También puedes pedirle a Claude que haga la instalación

Si quieres automatizar casi todo el proceso, pega este prompt en Claude Code:

prompt
Quiero que instales el plugin oficial de Codex de OpenAI en mi Claude Code.

Hazlo utilizando comandos de terminal.

Primero revisa si el plugin ya está instalado.
Ejecuta: claude plugin list

Si ya aparece codex@openai-codex, no vuelvas a instalarlo.

Si no aparece, agrega el marketplace:
claude plugin marketplace add openai/codex-plugin-cc

Después instala el plugin para toda mi cuenta:
claude plugin install codex@openai-codex --scope user --yes

Después vuelve a ejecutar: claude plugin list
Comprueba que el plugin esté instalado y habilitado.

Después comprueba si Codex está instalado: codex --version

Si no existe, instala: npm install -g @openai/codex

No utilices sudo si npm tiene problemas de permisos. En ese caso, detente y muéstrame el error.
No intentes iniciar sesión en Codex. Esa parte la haré yo.

Al terminar, dime:
1. Si el marketplace quedó agregado.
2. Si el plugin quedó instalado.
3. Qué versión del plugin está instalada.
4. Si Codex CLI está instalado.
5. Qué pasos me faltan hacer manualmente.

No edites ningún archivo de mi proyecto.
No ejecutes nada que no esté especificado arriba.

Después de que Claude termine, tú solo necesitas hacer:

texto
/reload-plugins

/codex:setup

5. El plugin instalado no es suficiente

Instalar el plugin no significa automáticamente que Claude vaya a delegar trabajo en Codex. Tienes que enseñarle cómo repartirlo. La mejor forma es dejar la regla escrita en CLAUDE.md, para que Claude la lea cada vez que abra el proyecto.

6. Define quién hace qué

Claude = cerebro

  • Entender el problema y hacer preguntas si falta información.
  • Crear el plan y decidir la arquitectura.
  • Decidir qué archivos hay que modificar.
  • Revisar el resultado de Codex.

Codex = ejecución

Codex debe recibir construcciones largas, código repetitivo, refactors grandes, tareas que afectan muchos archivos y errores que Claude ya intentó solucionar sin éxito.

7. Añade la regla a tu CLAUDE.md

Dile a Claude:

prompt
Quiero dejar por escrito en el CLAUDE.md de este proyecto cómo repartir el trabajo entre Claude y Codex.

Primero revisa si ya existe CLAUDE.md. Si existe, léelo completo y comprueba si ya hay alguna sección relacionada con Codex o delegación de tareas. No dupliques instrucciones existentes.

Si no existe una regla de reparto, agrega al final una sección llamada: "Reparto con Codex".

La regla debe establecer:
- Claude entiende el problema, crea el plan, decide la arquitectura y revisa todo lo que devuelve Codex.
- Las tareas repetitivas y largas, los refactors grandes y los errores ya intentados se delegan a Codex.
- Claude debe utilizar el subagente codex-rescue cuando corresponda.
- Nada que devuelva Codex se considera automáticamente correcto.
- Si Codex falla dos veces con la misma tarea, el problema vuelve a Claude.
- Claude debe decirme qué delegó y qué resultado recibió.

No modifiques ninguna otra parte del CLAUDE.md.
Cuando termines, muéstrame exactamente qué agregaste.

8. Si quieres hacerlo manualmente

markdown
## Reparto con Codex

El trabajo se divide entre Claude y Codex.

### Claude
- Entender el problema.
- Preguntar lo que falte.
- Crear el plan.
- Decidir la arquitectura.
- Revisar todo lo que vuelva de Codex.

### Codex
Delegar:
- Construcción repetitiva y larga.
- Refactors grandes.
- Tareas que afectan múltiples archivos.
- Errores que ya fueron intentados y siguen sin resolverse.

### Reglas
- Claude siempre revisa el resultado de Codex.
- Si Codex falla dos veces en la misma tarea, la tarea vuelve a Claude.
- Delegar no significa dejar de supervisar.
- Claude debe informar qué se delegó y qué resultado volvió.

9. Los comandos que tienes disponibles

ComandoPara qué sirve
/codex:setupConfigurar y comprobar Codex
/codex:reviewRevisar código
/codex:adversarial-reviewHacer una revisión crítica
/codex:rescueDelegar una tarea a Codex
/codex:transferPasar una conversación completa a Codex
/codex:statusVer trabajos activos
/codex:resultVer el resultado de un trabajo
/codex:cancelCancelar un trabajo

El comando más importante es /codex:rescue: es el que realmente delega el trabajo pesado a Codex.

10. El flujo que deberías usar normalmente

Paso 1. Pídele a Claude que haga el plan

prompt
Quiero agregar [FEATURE] a este proyecto.

Primero analiza el proyecto y crea un plan. No escribas código todavía.

Divide el trabajo entre:
[PLAN] Decisiones que debes tomar tú.
[EJECUCIÓN] Trabajo que debería hacer Codex.

Para cada tarea de ejecución dime:
- Qué archivo debe modificar.
- Qué debe cambiar.
- Qué no debe cambiar.
- Cómo comprobaremos que funciona.

Espera mi aprobación antes de ejecutar.

11. Cuando Claude se atasque

Si Claude intenta solucionar un error dos veces y sigue fallando, no le pidas una tercera vez lo mismo. Usa /codex:rescue y dale contexto:

prompt
Contexto:

Estoy trabajando en [DESCRIPCIÓN DEL PROYECTO].

El error es:
[ERROR COMPLETO]

Ya intentamos:
1. [PRIMER INTENTO]
2. [SEGUNDO INTENTO]

Quiero que:
1. Encuentres la causa raíz.
2. Revises primero configuración y datos antes de asumir que es código.
3. Apliques el arreglo directamente.
4. No agregues dependencias nuevas sin avisar.
5. Me entregues un resumen de qué lo causaba, qué modificaste y qué debería comprobar.

12. Usa Codex como segundo par de ojos

Ejecuta /codex:adversarial-review y usa este prompt:

prompt
Revisa los cambios actuales de forma crítica.

Busca:
1. Decisiones de arquitectura innecesariamente complejas.
2. Casos límite que no se estén manejando.
3. Dependencias nuevas que podrían evitarse.
4. Código duplicado.
5. Abstracciones innecesarias.
6. Posibles problemas que todavía no sean evidentes.

No modifiques ningún archivo.

Devuélveme los problemas ordenados por prioridad. Para cada problema indica archivo, línea, problema y qué podría pasar si no se corrige.

Al final dime qué está bien resuelto.

13. Delega trabajos largos

Puedes dejar a Codex trabajando en una tarea grande mientras continúas con Claude. Ejecuta /codex:rescue y después:

prompt
Limpia [MÓDULO/CARPETA].

Objetivos:
1. [OBJETIVO]
2. [OBJETIVO]
3. [OBJETIVO]

Reglas:
- No rompas las interfaces existentes.
- No cambies funciones públicas sin avisar.
- No agregues funcionalidades nuevas.
- Si una prueba existente falla, detente y repórtalo.
- Resume los cambios archivo por archivo.

Trabaja en segundo plano.

Revisa el estado con /codex:status y, cuando termine, usa /codex:result.

14. Después de Codex, vuelve a Claude

prompt
Codex acaba de terminar este trabajo.

Lee los archivos que modificó. Ahora:
1. Escribe pruebas para los casos que solucionó.
2. Incluye específicamente el caso que estaba fallando.
3. Actualiza la documentación únicamente si el comportamiento cambió.
4. No rehagas la implementación de Codex.
5. Si encuentras algo que debería corregirse, no lo arregles todavía.

Crea una sección llamada "Pendientes" y coloca ahí cualquier problema que encuentres.

15. Retomar una sesión de Codex

bash
codex resume --last

Después puedes darle este contexto:

prompt
Continúa donde quedamos.

Pendiente:
1. [PUNTO 1]
2. [PUNTO 2]
3. [PUNTO 3]

Antes de ejecutar nada:
- Dime qué vas a tocar primero.
- Si alguna decisión anterior ya no aplica, avísame.
- Si algo ya está terminado, no lo repitas.

Al finalizar dime qué cerraste, qué quedó pendiente y qué debería comprobar.

16. ¿Qué cuenta de uso estás gastando?

Claude

Consume el límite de Claude cuando analiza el proyecto, crea el plan, decide la arquitectura, revisa el resultado, escribe pruebas y documenta.

Codex

Consume el límite de tu cuenta de ChatGPT cuando escribe código, modifica archivos, ejecuta tareas delegadas, hace revisiones y trabaja en tareas largas.

El objetivo no es simplemente usar dos modelos: es repartir el consumo entre dos sistemas.

El uso de Codex comparte la bolsa de uso correspondiente de tu cuenta de ChatGPT con otros productos o funciones que usen ese mismo límite; no asumas que todo está disponible exclusivamente para Codex.

17. ¿Necesito pagar ChatGPT?

Los límites concretos dependen del plan y pueden cambiar. Comprueba las condiciones actuales de tu cuenta antes de asumir una cantidad determinada de uso.

18. Si algo no funciona

Cuando una delegación falle, ejecuta en una terminal normal:

bash
codex doctor

Esto revisa el estado de la instalación y de la sesión de Codex. También puedes volver a comprobar desde Claude Code con /codex:setup.
