Google Skills para Claude: guía para instalarlos y usarlos

Qué hace cada Google Skill, cuándo Claude lo activa y cómo instalar los más útiles para Google Cloud desde cero.

8 min de lecturaClaude a fondoGoogle CloudFirebaseGemini API
Ideal para
  • Personas que empiezan con Claude Code y Google Cloud
  • Developers que construyen con Firebase, Cloud Run o Gemini
  • Equipos que quieren seguir prácticas oficiales
  • Quien quiere instalar Skills sin saturar el contexto
Qué obtienes
  • Qué hace un Skill y cuándo Claude lo utiliza
  • Instalación por proyecto y global
  • Skills clave de Google explicados simple
  • Prompts para Firebase, Cloud Run y Gemini

Google publicó un repositorio oficial de Agent Skills. Con ellos, Claude puede cargar el playbook adecuado al trabajar con Firebase, Cloud Run, Gemini, BigQuery y otras tecnologías de Google.

En resumen

El repositorio está en github.com/google/skills. Instala solo los Skills que realmente necesitas: Claude conoce sus descripciones y carga las instrucciones completas únicamente cuando una tarea coincide con ellas.

1) Qué son los Google Skills

Un Skill es una pequeña carpeta que contiene un archivo SKILL.md. Incluye instrucciones oficiales, ejemplos y buenas prácticas para trabajar con una tecnología concreta.

En lugar de pegar documentación completa en cada prompt, Claude solo carga el Skill adecuado cuando hace falta. Eso mejora la precisión, reduce el contexto innecesario y hace que el equipo siga el mismo enfoque en cada proyecto.

2) Cuándo Claude utiliza un Skill

  1. Descubrimiento: al iniciar una sesión, Claude Code revisa tus carpetas de Skills y carga únicamente el nombre y la descripción de cada uno.
  2. Activación: si tu solicitud coincide con la descripción —por ejemplo, desplegar una app— carga el SKILL.md correspondiente.
  3. Ejecución: usa sus instrucciones, fragmentos de código y archivos de referencia durante la tarea.

Dónde se guardan

Para un proyecto: .claude/skills/<nombre-del-skill>/SKILL.md. Para todos tus proyectos: ~/.claude/skills/<nombre-del-skill>/SKILL.md. Mantén en el repositorio los Skills específicos de cliente, proyecto o stack.

3) Configuración para principiantes

Opción A — un solo comando (recomendada)

bash
npx skills add google/skills

Se abrirá un selector para elegir los Skills. Empieza con dos o tres, no instales todos de una vez.

Opción B — plugins de Claude Code

bash
claude plugin marketplace add google/skills
claude plugin install <plugin>@google-plugins

Opción C — instalación manual: entra al repositorio, busca el Skill, copia su SKILL.md dentro de .claude/skills/<nombre-del-skill>/ y reinicia Claude Code.

4) La librería de Skills más útil

Para empezar en Google Cloud

  • Onboarding to Google Cloud: configura correctamente un proyecto nuevo.
  • Authenticating to Google Cloud: credenciales, cuentas de servicio, ADC e IAM. Configúralo antes que otros Skills de Cloud.
  • Foundation Builder: una base de infraestructura organizada para un negocio.

Web y hosting

  • Firebase Basics: Firestore, reglas de seguridad, autenticación y Functions. Ideal para portales y dashboards.
  • Cloud Run Basics: contenedores, escalabilidad y tráfico. Úsalo cuando la app está lista pero falta desplegarla.

IA, datos y desarrollo

  • Gemini API: SDKs y endpoints actuales para integrar IA dentro de tu aplicación.
  • BigQuery: consultas, particionamiento, esquemas y control de costos para analytics.
  • AlloyDB / Cloud SQL: buenas prácticas para PostgreSQL y MySQL administrados.
  • gcloud CLI: le enseña a Claude a usar bien la línea de comandos de Google Cloud; suele valer la pena instalarlo globalmente.

Seguridad y arquitectura

  • GKE + Platform / Workload Security: clusters, Workload Identity, node pools y hardening. Puedes ignorarlo si no usas Kubernetes.
  • Well-Architected Framework: seguridad, confiabilidad, costo, rendimiento, operaciones y sostenibilidad antes de producción.
  • Network Observability: para diagnosticar problemas de conectividad en Google Cloud.

5) Los 3 Skills para empezar

  1. Firebase Basics para autenticación, base de datos y hosting.
  2. Cloud Run Basics para transformar el deployment en una tarea guiada.
  3. Gemini API para construir funciones de IA usando el SDK actual.

6) Prompts para empezar

Firebase

plain text
Usando el Firebase Skill, créame un portal para clientes con autenticación por email, una base de datos de Firestore para almacenar proyectos y reglas de seguridad que garanticen que cada cliente solo pueda ver sus propios datos.

Cloud Run

plain text
Usando el Cloud Run Skill, convierte esta aplicación en un contenedor y despliega la aplicación en Cloud Run con configuraciones de escalabilidad razonables.

Explícame cada comando de gcloud antes de ejecutarlo.

Gemini

plain text
Usando el Gemini API Skill, agrega una funcionalidad de resumen con AI a esta aplicación utilizando el SDK más reciente de Gemini.

No utilices endpoints obsoletos.

7) Errores que debes evitar

  1. Instalar todos los Skills de una vez: más Skills significan más descripciones en el contexto.
  2. Saltarte autenticación: muchos problemas de Google Cloud son de credenciales y permisos.
  3. Poner todo globalmente: los Skills específicos de un proyecto deben vivir en .claude/skills/.
  4. Olvidar reiniciar Claude Code: descubre Skills al iniciar una sesión.
  5. Pensar que el Skill lo hace todo: aporta el playbook oficial, pero todavía debes definir claramente qué quieres construir.

Tip práctico: si usarás Google Cloud, configura primero autenticación. Después instala Firebase, Cloud Run o Gemini según el proyecto real que estés construyendo.
