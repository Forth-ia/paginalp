Instagram Agent Skill en Claude: guía de instalación

Instala 13 skills de Instagram desde Claude Code pegando un solo mensaje: Claude se encarga del proceso y tú autorizas solo lo necesario.

5 min de lecturaClaude a fondoClaude CodeInstagramGitHub
Ideal para
  • Quien usa Claude Code y crea contenido para Instagram
  • Personas que quieren instalar skills sin usar Terminal
  • Equipos que quieren reutilizar skills en distintos proyectos
Qué obtienes
  • El mensaje exacto para pegar en Claude Code
  • Cómo aprobar permisos con criterio
  • Cómo comprobar las 13 skills instaladas
  • Qué hacer si Claude no puede completar la instalación
Vas a instalar 13 skills de Instagram usando Claude Code. No necesitas escribir comandos manualmente: pega el enlace del repositorio, deja que Claude revise las instrucciones oficiales y autoriza únicamente las acciones necesarias.

Repositorio

github.com/Jakeschincariol/instagram-agent-skill

Paso 1. Abre Claude Code

Abre la aplicación de Claude Code en tu Mac o entra desde VS Code.

Importante: necesitas Claude Code, no solamente una conversación normal en Claude.ai, porque debe poder instalar archivos en tu computador.

Paso 2. Copia y pega este mensaje

Pégalo dentro de una sesión de Claude Code:

plain text
Quiero que instales y configures este repositorio de GitHub en mi Claude Code:

https://github.com/Jakeschincariol/instagram-agent-skill

Haz todo el proceso por mí, paso a paso:

1. Lee el README y revisa las instrucciones oficiales del repositorio.
2. Identifica las 13 skills incluidas y cómo deben instalarse.
3. Descarga el repositorio e instala todas las skills para que pueda utilizarlas en mis diferentes proyectos de Claude Code.
4. Configura los archivos adicionales que sean necesarios según las instrucciones oficiales.
5. No dupliques skills que ya estén instaladas.
6. Verifica que las skills hayan quedado correctamente instaladas y explícame cómo activarlas.
7. Si necesitas permisos para ejecutar alguna acción, pídemelos cuando corresponda.

Hazlo directamente desde tus herramientas disponibles, sin pedirme que abra Terminal ni que ejecute comandos manualmente.

Si no puedes completar algún paso desde tu entorno actual, explícame exactamente qué falta y cuál es la alternativa más sencilla.

Paso 3. Autoriza la instalación

Claude puede pedirte permiso para descargar el repositorio, acceder a archivos o ejecutar comandos. Revisa cada solicitud y autoriza solo las necesarias para instalar las skills.

  • Si pregunta dónde instalarlas, elige la opción global para usarlas en varios proyectos, si el repositorio la admite.
  • No apruebes acciones destructivas ni cambios que no entiendas.
  • Si algo no coincide con el README del repositorio, pide a Claude que se detenga y te explique la diferencia.

Paso 4. Comprueba que quedó instalado

Cuando Claude termine, pídele esta verificación:

plain text
Verifica que la instalación esté completa. Muéstrame las 13 skills instaladas, dime cómo activar cada una y ejecuta una prueba de /ig-reel para confirmar que funciona.

Si Claude confirma que todo está listo, prueba a escribir /ig-reel en la sesión correspondiente.

¿Y si Claude no puede instalarlo automáticamente?

Puede ocurrir si estás usando Claude.ai en vez de Claude Code, si no tiene acceso al repositorio o si sus permisos no permiten modificar los archivos necesarios.

En ese caso, pídele que use el método oficial de instalación mediante plugins, si está disponible. La idea es que Claude haga el trabajo: tú solo pegas el enlace, envías el mensaje y autorizas los permisos necesarios.

Tip práctico: al terminar, abre un proyecto de prueba y ejecuta /ig-reel. Así confirmas no solo que los archivos existen, sino que Claude Code detecta la skill correctamente.
