Google Skills para Claude: guía para instalarlos y usarlos

Qué hace cada Google Skill, cuándo Claude lo activa y cómo instalar los más útiles para Google Cloud desde cero.

8 min de lecturaClaude a fondoGoogle CloudFirebase
Google publicó un repositorio oficial de Agent Skills. Con ellos, Claude puede cargar el playbook adecuado al trabajar con Firebase, Cloud Run, Gemini, BigQuery y otras tecnologías de Google.

1) Qué son los Google Skills

Un Skill es una pequeña carpeta con un archivo SKILL.md: incluye instrucciones oficiales, ejemplos y buenas prácticas para una tecnología concreta.

2) Cuándo Claude utiliza un Skill

Claude descubre los Skills al iniciar una sesión y carga el indicado cuando tu tarea coincide con su descripción.
